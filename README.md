# Loopit Games

Twenty standalone 3D H5 games across two independent briefs. Each brief has its own top-level folder and each game inside it has a complete WebGL scene, English UI, sound, three physically connected spaces with different objectives, and replay.

Each game has four or five distinct challenges across three rooms, including mechanics designed exclusively for that game. Play again changes the orders, boards, routes, and operating conditions.

Each room starts with three tries. Committed errors spend a try. Each challenge timer begins after the first gameplay action. Retry keeps completed challenges and earlier room rewards.

Tap objects and floor tiles in the 3D scene. Lights, silhouettes, progress marks, and short goals guide play, and touching the goal expands the instructions. Each game has a scene-specific 3D ending driven by its three completed tasks.

Open any game’s `index.html` in a modern browser. To serve the whole repository locally, run `python3 -m http.server 8000` from this directory.

## Codex Skill

Use `$loopit-game-production` to turn a game brief into tested 3D H5 games, commit them to GitHub, and import a pinned build into editable Loopit drafts. [安装和使用说明](docs/loopit-game-production.md)
